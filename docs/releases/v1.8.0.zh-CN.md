# PulseBar 1.8.0

[English](v1.8.0.md) | 简体中文

- 底部统一为总览、应用、事件和设置导航。
- 安装盘只显示 App 和 Applications 文件夹入口，左右排列为两个大图标。
- 默认刷新间隔为 2 秒，语言菜单中的 English 排在简体中文前面。
- 详情栏使用相同宽度，一次完成导航状态更新，避免切换时闪烁。
- 语言等原生菜单不再被当成外部点击关闭监控面板。
- 更多菜单收纳更新、重置和退出；右击菜单栏读数也可快速操作。
- 新增轻量打开、详情浮现、按钮反馈和事件展开动画，尊重系统“减少动态效果”。
- 设置按用途分组，应用页提供 CPU / 内存切换，窄屏使用面板内部详情。
- Escape 先返回总览，再关闭面板；Command-1 至 Command-4 切换主要页面。

支持 macOS 13 及以上、Apple Silicon 和 Intel，保留现有设置、监控方式与本地事件。
