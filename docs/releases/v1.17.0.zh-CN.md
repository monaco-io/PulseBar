# PulseBar 1.17.0

网络与磁盘速率分别支持“自动单位”或“固定 MB/s”。各方向独立选择单位；菜单栏双行各带单位，单行保留大字号。KB/s 显示整数，MB/s 小于 100 时保留一位小数，达到 100 后显示整数。

修复从设置打开 PulseBar 助手的问题，改善带电池设备首次打开总览的布局，更新应用图标并精简界面文案。

应用排行和温度需单独安装 PulseBar 助手 1.0.2。主程序通过 Mac App Store 分发。连接正式助手的本地构建必须使用同团队的 Developer ID 证书，构建脚本新增 `--local --developer-id` 选项。

验证包括 121 项 Store 配置测试、原生菜单栏绘图、正式助手的真实排行和温度，以及 arm64/x86_64 沙盒构建。App Store 提交与审核结果单独记录于 `docs/VALIDATION.md`。
