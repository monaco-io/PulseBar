# PulseBar 1.9.0

[English](v1.9.0.md) | 简体中文

- 总览新增可读取的 CPU、GPU、内存、存储和电池温度（°C）。每项显示已知且系统可访问传感器中当前有效读数的最高值。
- 缺失、无权限或无效的温度读数自动隐藏；全部温度不可读时隐藏整行，其他监控照常运行。
- 总览温度在后台进行只读采样，最快每 5 秒读取一次，无需管理员权限或特权辅助服务。

温度可用性取决于 Mac 型号和 macOS 版本。本机已读取 Apple Silicon 真实传感器；尚未在 Intel 真机测试。详见[温度兼容性说明](../TEMPERATURES.md)。

支持 macOS 13 及以上、Apple Silicon 和 Intel，保留现有设置与本地事件历史。
