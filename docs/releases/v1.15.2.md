# PulseBar 1.15.2

- Give single-row menu bar labels, numbers, and units a consistent system menu bar font size. Individual upload, download, disk read, and disk write readings use tighter spacing; large values expand instead of shrinking the text. Paired readings keep their compact two-row layout.
- Avoid unnecessary filesystem checks when reading process names.
- Include the companion helper fixes in this source release: responsive enable/disable controls, clearer background-item approval guidance, an Open PulseBar shortcut, a fresh launch-agent registration, and shared sampling across reconnecting clients.
- Added English and Simplified Chinese product screenshots and expanded menu bar setup guidance.

App Store users can install [PulseBar Helper 1.0.1](https://github.com/monaco-io/PulseBar/releases/tag/helper-v1.0.1) separately to receive the helper fixes without waiting for a main-app update. The helper keeps the existing authenticated local endpoint and works with the current App Store app. Disable the old helper before replacing it, then enable the new one.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. The direct GitHub app uses ad-hoc signing and signed Sparkle updates; it is not Apple notarized. The optional helper is distributed separately with Developer ID signing and Apple notarization.

## Your menu bar, your choice

Assign CPU, memory, storage, supported GPU utilization or battery charge to each of the three rings. Show rings and numbers separately, and choose upload, download, read and write independently. One direction uses a full-size single row; paired directions share a unit in two compact rows. CPU and storage use green below 80%, yellow at 80–90%, and red above 90%; memory follows macOS memory pressure.
