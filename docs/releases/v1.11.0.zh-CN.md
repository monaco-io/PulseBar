# PulseBar 1.11.0

- 总览使用 560 pt 双列布局，高度最多 660 pt。CPU、内存、GPU、存储、网络与可用的内置电池读数保留硬件标题及内部横纵分隔，仅移除包住全部硬件的外卡底色和边框。
- 指标使用数字与文字，不显示进度条。CPU、内存、物理磁盘和网络的四组联动历史改为无面积填充的折线，保留查看、均值和峰值。
- 可用内容宽度不足 500 pt 时使用单列，较矮窗口保留滚动，标题与导航固定；应用、事件和设置继续按可用空间使用侧栏或面板内详情。
- 修复英文 Events 空状态说明在窄面板中的换行，完整显示文案。

温度与其他可选硬件读数继续遵循现有有效性和缺失隐藏规则。采样、保存的设置、菜单栏选项和本地事件历史保持原有行为。

已在 Apple M4 iMac 上检查中英文、深浅外观及宽、窄、矮窗口。本轮未验证 Intel、macOS 13、MacBook 实体电池或多 GPU 真机。

支持 macOS 13+、Apple Silicon 与 Intel。沿用现有 ad-hoc 签名和带签名的 Sparkle 更新流程，尚无 Apple Developer ID 公证。
