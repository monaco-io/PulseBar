# PulseBar 1.17.0

Network and disk rates each offer Automatic units or Fixed MB/s. Each direction chooses its own unit; paired menu bar rows show two units, while a single row retains full-size text. KB/s uses whole numbers, MB/s below 100 uses one decimal place, and larger MB/s values use whole numbers.

This update also fixes opening PulseBar Helper from Settings, improves the first overview layout on Macs with a battery, updates the app icon, and simplifies interface text.

App rankings and temperatures require the separately installed PulseBar Helper 1.0.2. The main app is distributed through the Mac App Store. Local builds that connect to the public helper must use the team's Developer ID certificate; the build script now provides `--local --developer-id` for that workflow.

Validation: 121 Store-configuration tests, native menu bar rendering, real Helper rankings and temperatures, and arm64/x86_64 sandboxed builds. App Store submission and approval are recorded separately in `docs/VALIDATION.md`.
