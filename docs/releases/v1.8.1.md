# PulseBar 1.8.1

- Repeated launches now reopen the existing panel and keep one main instance per macOS user, including updated app copies in different folders.
- Simultaneous launches are handled safely, and the app can restart after a crash without manual lock cleanup.
- Background sampling releases temporary objects promptly, reducing memory accumulation. The command-line sampling tool uses the same explicit cleanup boundary.
- Menu bar readings avoid redundant image rendering, and chart inspection skips unused history statistics.
- Monitor cleanup now removes timers and workspace observers when the monitor is released.

Requires macOS 13 or later, on Apple Silicon or Intel. Existing preferences and local event history are preserved.
