# PulseBar 1.15.2

- 菜单栏单行读数的标签、数字和单位统一使用系统菜单栏字号。单独显示上传、下载、磁盘读或写时缩小间距；大数值自动扩展宽度，保持完整字号。同组两项读数继续使用紧凑的上下双行布局。
- 读取进程名称时避免多余的文件系统检查。
- 源码包含助手修复：启用和停用时保持界面响应，明确提示后台项目审批要求，增加“打开 PulseBar”按钮，使用新的后台服务注册，并在客户端重连时共用采样缓存。

商店版用户可单独安装 [PulseBar Helper 1.0.1](https://github.com/monaco-io/PulseBar/releases/tag/helper-v1.0.1)，无需等待主程序更新即可获得助手修复。助手保留原有的本地认证连接，兼容当前商店版。更新时先停用旧助手，替换后再启用新版。

需要 macOS 13 或更新版本，支持 Apple Silicon 和 Intel，保留已有偏好设置和本地事件历史。GitHub 主程序使用临时签名和 Sparkle 签名更新，未经过 Apple 公证；可选助手单独使用 Developer ID 签名并经过 Apple 公证。
