# PulseBar 1.8.0

## What's changed

- A clearer bottom navigation for Overview, Apps, Events, and Settings.
- A simpler disk image with just the app and Applications folder shortcut, displayed as two large icons.
- A 2-second default refresh interval and English listed above Simplified Chinese in the language menu.
- A consistent detail width and atomic navigation to prevent flicker when switching views.
- Native dropdown menus remain open without dismissing the monitoring panel.
- A More menu for updates, Reset, and Quit, plus a right-click menu on the menu bar readings.
- Subtle opening, detail reveal, button feedback, and event expansion animations that respect Reduce Motion.
- Grouped settings, direct CPU/Memory tabs in Apps, and a compact detail layout for narrow displays.
- Escape returns from details to Overview, then closes the panel. Command-1 through Command-4 select the main destinations.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences, monitoring behavior, and local event history are preserved.
