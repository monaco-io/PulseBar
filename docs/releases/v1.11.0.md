# PulseBar 1.11.0

- The overview uses a 560-point, two-column layout with a maximum height of 660 points. CPU, memory, GPU, storage, network, and available internal-battery readings retain their hardware headings and internal dividers, while the surrounding hardware-card background and border are removed.
- Readings use numbers and text without progress bars. The four linked CPU, memory, physical-disk, and network histories use lines without filled areas, retaining their inspection, averages, and peaks.
- Available content widths below 500 points use a single column; shorter windows retain scrolling. The header and navigation stay fixed. Apps, Events, and Settings use the existing side panel or inline details when space is limited.
- English Events empty-state text wraps fully in narrow panels.

Available temperatures and other optional hardware readings keep the existing validity and absence rules. Sampling, saved preferences, menu-bar choices, and local event history are unchanged.

The layout was checked in English and Simplified Chinese, light and dark appearances, and wide, narrow, and short windows on an Apple M4 iMac. Intel, macOS 13, physical MacBook battery, and multiple-GPU hardware have not been tested in this round.

Requires macOS 13 or later, on Apple Silicon or Intel. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
