# PulseBar 1.16.0

- Reorganizes the overview into four equally sized tiles. CPU and GPU share one card, with separate readings and details.
- Uses matching native macOS Settings and More controls.
- Downloads the optional PulseBar Helper directly as a signed, notarized macOS PKG. Installation and enabling remain explicit user actions.
- Distributes the main app through the Mac App Store; GitHub releases contain only the optional helper.

Store build: 30. Helper: 1.0.2 (3).
