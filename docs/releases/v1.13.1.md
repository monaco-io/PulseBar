# PulseBar 1.13.1

- Disk and network readings use two compact rows: read above write, and download above upload. Each pair shares one centered MB/s label, with clear R/W and direction labels.
- Fixed widths and right-aligned numbers prevent the menu bar from shifting as rates change. Very long readings fit within their own columns; hover details retain full-size values.
- Hover over the disk or network readings to see labeled live rates and session totals, using the same native panel interaction as the CPU and memory rings. Moving away or clicking dismisses the panel, and switching between metrics keeps the correct details visible.
- The rings' hover panel lists CPU first, then memory, with memory pressure underneath.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
