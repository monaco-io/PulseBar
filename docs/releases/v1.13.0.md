# PulseBar 1.13.0

- A compact overview brings CPU, memory, network, storage, and available GPU/battery readings into one column. Hover over a hardware row for an independent detail window; click or pin it to keep it open. CPU and memory details include the top apps.
- Overview, detail, settings, and event windows fit their content, up to 80% of the usable screen height. They use native Liquid Glass on macOS 26 and native popover material on earlier systems, with native controls and respect for accessibility settings.
- The menu bar now shows concentric memory and CPU rings with clear tracks. The outer memory ring follows macOS memory pressure; the inner CPU ring reflects utilization. A hover panel explains both rings and shows live values. Disk reads/writes share one MB/s label, and network downloads/uploads share another.
- More reliable menu-bar opening and closing prevents delayed click events from dismissing a newly opened panel. Detail windows apply their measured height before the first appearance, preventing clipped titles and readings. The glass container now clips its outer corners and refreshes the window shadow as its size changes.
- App rankings better group helper and WebKit/XPC processes with their owning app, including when the owner's resource counters are unavailable. Existing bundle and parent-process attribution remains the fallback.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
