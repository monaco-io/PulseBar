# PulseBar 1.15.0

- Configure three menu bar rings independently. The default order is storage, memory, and CPU; each ring can also show supported GPU or battery readings. Thicker 3 pt strokes keep the three layers readable.
- Show or hide rings and numeric readings separately. Choose CPU, memory, disk read, disk write, upload, and download numbers independently. Existing display choices are migrated automatically.
- CPU and storage are green below 80%, yellow from 80% through 90%, and soft red above 90%. Memory continues to follow macOS memory pressure. Normal status colors use green throughout the interface.
- Remove click-to-pin behavior and improve immediate click feedback. Controls use native glass effects where supported, with compatible materials on older macOS versions and reduced-motion support.
- Keep hover details and VoiceOver descriptions aligned with the selected rings and rate directions.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. The GitHub download uses the existing ad-hoc signing and signed Sparkle update flow; it is not Apple notarized. The App Store build is distributed separately and requires Apple's approval.
