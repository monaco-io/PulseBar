# PulseBar 1.9.0

- The overview now shows available CPU, GPU, memory, storage, and battery temperatures in °C. Each component displays the highest valid reading from its known, exposed sensors.
- Missing, inaccessible, or invalid temperature readings are hidden. If no supported temperatures are readable, the temperature row stays hidden; other monitoring continues normally.
- Read-only overview temperature sampling runs in the background at most once every 5 seconds, without administrator access or a privileged helper.

Temperature availability depends on the Mac and macOS version. Apple Silicon sensor readings have been checked locally; Intel hardware has not been tested. See [temperature compatibility](https://github.com/monaco-io/PulseBar/blob/main/docs/TEMPERATURES.md).

Requires macOS 13 or later, on Apple Silicon or Intel. Existing preferences and local event history are preserved.
