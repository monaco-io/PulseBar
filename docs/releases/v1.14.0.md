# PulseBar 1.14.0

- The menu bar now has three concentric rings: startup-volume storage on the outside, memory in the middle, and CPU on the inside. Equal 2.5 pt strokes, narrow transparent gaps, and a hollow center keep the layers distinct at menu-bar size.
- CPU and storage use green below 60%, yellow at 60–80%, and the new soft red `#FF8080` above 80%. Memory still follows macOS memory pressure and uses the same soft red for critical pressure. The danger color is identical in light and dark appearances.
- Hover details keep CPU first and now include the middle/outer ring labels, storage usage, and available space. Accessibility descriptions follow the same mapping. The disk toggle controls both its capacity ring and its read/write readings.
- Keeps fixed-width read/write and upload/download columns, with upload above download and a shared MB/s label for each pair.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
