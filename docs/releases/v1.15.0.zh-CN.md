# PulseBar 1.15.0

- 三个菜单栏圆环均可自定义指标，默认外圈磁盘容量、中圈内存、内圈 CPU，也可选择设备支持的 GPU 或电池读数。圆环加粗至 3 pt。
- 圆环与数值分别控制显隐；CPU、内存、磁盘读取、磁盘写入、上传、下载数值均可单独选择。自动保留并迁移已有显示设置。
- CPU 和磁盘容量低于 80% 为绿色，80% 至 90% 为黄色，超过 90% 为柔和红色。内存继续根据 macOS 内存压力判断；界面正常状态统一使用绿色。
- 移除点击置顶行为，改善点击即时反馈。在支持的系统使用原生玻璃效果，旧版 macOS 使用兼容材质，并遵循减少动态效果设置。
- 悬停提示和 VoiceOver 描述随所选圆环与速率方向同步更新。

需要 macOS 13 或更新版本，支持 Apple Silicon 和 Intel，保留已有偏好设置和本地事件历史。GitHub 安装包沿用临时签名和 Sparkle 签名更新流程，未经过 Apple 公证。App Store 版单独分发，需要通过 Apple 审核。
