# PulseBar 1.10.0

- The overview is organized into CPU, memory, GPU, storage, network, and the Mac's internal battery. Available temperatures appear alongside their hardware headings.
- CPU shows logical-core count. Memory keeps usage, app/wired/compressed bytes, pressure, and Swap together with its history.
- GPU utilization is shown separately for each named hardware device when its driver provides a valid reading. Percentages from different GPUs are not added together; the component temperature is not attributed to a particular device.
- Storage adds startup-volume used, total, and ordinary available space, clearly separated from physical disk read/write activity. APFS shared-container space is not a sum of the startup volume's file sizes.
- A present internal battery can show charge, power/charging state, maximum capacity, cycle count, and macOS time estimates when available. Desktops without an internal battery hide this section; UPS and peripheral batteries are excluded.
- Hardware sections scroll between a fixed header and navigation. The four existing histories, app rankings, menu-bar choices, saved preferences, and local event history are preserved.

Unavailable or invalid optional hardware readings are hidden. GPU and temperature reads run in the background no faster than every 5 seconds; volume capacity and battery use a 30-second minimum, with longer configured refresh intervals respected. No administrator access or privileged helper is introduced.

The layout and real CPU/GPU/storage readings were checked on an Apple M4 iMac. Intel hardware and physical MacBook battery behavior have not been tested in this round. Availability depends on the Mac, driver, and macOS version. See [hardware modules and measurement scope](https://github.com/monaco-io/PulseBar/blob/main/docs/HARDWARE-MODULES.md).

Requires macOS 13 or later, on Apple Silicon or Intel. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
