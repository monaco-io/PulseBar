# PulseBar 1.7.0

Historical release notes. The old GitHub Release has been removed; download the [latest DMG](https://github.com/monaco-io/PulseBar/releases/latest/download/PulseBar.dmg).

## Installation and updates

- Universal macOS 13+ app for Apple Silicon and Intel.
- Software update settings with manual checks, daily automatic checks, version information, and a download link.
- Sparkle updates with download, installation, and relaunch inside the app. Update archives and feeds use Ed25519 signature verification.
- Automated GitHub tests, packaging, and releases. Starting with 1.7.1, releases provide only a DMG and host the feed separately.

## Performance insights

- Top CPU and memory apps, memory pressure, and swap trends.
- Linked chart inspection, time-weighted averages, and peaks.
- A local timeline of sustained CPU load and memory-pressure events, including app snapshots.
- Optional notifications, separate cooldowns, and seven days of local event history.
- Sidebar positioning fixes and immediate switching between English and Simplified Chinese.

Versions 1.7.0 and earlier require one manual installation of 1.7.1 or later to migrate to the current update feed. Quit the old version before replacing it. The app is not Apple notarized; if blocked, verify its source and use **System Settings → Privacy & Security → Open Anyway**.
