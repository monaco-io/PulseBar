# PulseBar 1.7.0

[English](v1.7.0.md) | 简体中文

## 安装与更新

- 提供 macOS 13+ 通用安装包，同时支持 Apple Silicon 和 Intel。
- 新增“设置 → 软件更新”：检查更新、每日自动检查开关、版本号及下载入口。
- 接入 Sparkle，在应用内下载更新、安装并重启；更新文件和更新清单均有 Ed25519 签名校验。
- GitHub 自动测试、打包及发布 DMG、ZIP、更新清单和 SHA-256 校验文件。

## 性能洞察

- CPU / 内存占用最高的应用排行、内存压力和 Swap 趋势。
- 四张监控曲线的时间游标联动、所选时段的均值与峰值。
- CPU 持续高负载与内存压力异常事件时间线，保留当时的应用快照。
- 可选系统通知、独立通知冷却、最近 7 天的本地事件记录。
- 修正侧栏展开与窗口定位，保留中文 / English 即时切换。

## 首次安装

下载 **PulseBar.dmg**，打开后把 App 拖入 **Applications**。
当前版本尚无 Apple Developer ID 公证；如果 macOS 拦截，请确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。
1.6 及更早版本请先退出旧版，手动安装本版一次，此后可在应用内更新。
