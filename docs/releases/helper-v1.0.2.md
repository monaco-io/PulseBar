# PulseBar Helper 1.0.2

[简体中文](helper-v1.0.2.zh-CN.md)

- Install with the native macOS PKG installer. It places the helper in your personal Applications folder without dragging files or requesting administrator access.
- Open the helper from PulseBar Settings after installation, then explicitly enable its background service.
- App rankings and hardware temperatures continue to use the same authenticated, read-only local connection.

PulseBar itself is distributed and updated through the Mac App Store. This release contains only the optional helper.
