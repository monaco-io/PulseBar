# PulseBar 1.12.0

- 总览落地已审核的布局：首行为 CPU / 内存，第二行为存储 / 网络，下方为可用的 GPU / 内置电池。名称、标签统一左对齐，主数值和百分比统一右对齐。
- 各硬件分区依次安排主指标、辅助信息和历史。CPU 用户 / 系统与内存应用 / 联动 / 压缩采用一致的辅助列；保留全部可用指标，包括压力、Swap、物理磁盘标识、活动网卡和本次累计。
- CPU / 内存及磁盘 / 网络历史分别对齐，均值和峰值使用固定列位置；磁盘与网络的方向和累计采用同一顺序，保留历史联动查看。
- 总览宽 620 pt、高度最多 660 pt；可用内容宽度不足 500 pt 时使用单列，中部滚动，标题与导航固定。屏幕容纳 941 pt 展开宽度时使用 320 pt 详情侧栏，否则在面板内展示详情。
- 主百分比使用 28 pt 数字、双向速率使用 24 pt 数字，单位和辅助文字降低视觉权重；精度按指标语义保留，次数和时间估算仍为整数。硬件分区保留轻分隔，无外卡与进度条，历史仍为无面积填充的折线。

正式版本接入实际采样数据，不使用设计提案中的示例值。缺失或无效温度及可选硬件字段继续隐藏；采样、保存的设置、菜单栏选项与本地事件历史沿用原有行为。内置电池继续显示其全部有效字段，台式机不会凭空出现电池分区。

支持 macOS 13+、Apple Silicon 与 Intel。沿用现有 ad-hoc 签名和带签名的 Sparkle 更新流程，尚无 Apple Developer ID 公证。
