# PulseBar 1.12.0

- The overview follows the approved layout: CPU and memory first, storage and network next, with available GPU and internal-battery groups below. Names and labels align left; main values and percentages align right.
- Each hardware group separates its main readings, supporting facts, and history. CPU user/system and memory app/wired/compressed values use consistent supporting columns. All existing available readings remain visible, including pressure, swap, physical disk identities, interfaces, and session totals.
- CPU/memory and disk/network histories align within their rows. Averages and peaks use fixed columns, and disk/network directions and totals follow the same order. Linked history inspection is preserved.
- The overview is 620 points wide and at most 660 points high. Content widths below 500 points use one column; the middle scrolls while the header and navigation stay fixed. Details retain a 320-point side column when the screen accommodates the 941-point expanded panel, otherwise they stay inside the panel.
- Main percentages use 28-point digits and paired rates use 24-point digits, with quieter units and supporting text. Existing numeric precision follows each metric's meaning: counts and time estimates stay integers. Hardware groups retain light internal dividers without an outer card or progress bars; histories remain lines without filled areas.

This release uses production readings, rather than the proposal's sample data. Unavailable or invalid temperatures and optional hardware fields retain their existing absence rules. Sampling, saved preferences, menu-bar choices, and local event history keep their established behavior. A present internal battery continues to show each usable field; desktops do not acquire a battery section.

Requires macOS 13 or later, on Apple Silicon or Intel. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
