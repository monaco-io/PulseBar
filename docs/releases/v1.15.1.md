# PulseBar 1.15.1

- Make single-row menu bar readings easier to read: labels, numbers, and units now share the system menu bar font size.
- Tighten spacing for individual upload, download, disk read, and disk write readings. Ordinary rates reserve a compact, stable value column; larger values expand the column while keeping full-size text.
- Keep the compact two-row layout when both readings in a group are enabled.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. The GitHub download uses ad-hoc signing and signed Sparkle updates; it is not Apple notarized. The App Store version is distributed separately.
