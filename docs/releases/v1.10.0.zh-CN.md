# PulseBar 1.10.0

[English](v1.10.0.md) | 简体中文

- 总览按 CPU、内存、GPU、存储、网络及主机内置电池分区，可读取的温度归入对应硬件标题。
- CPU 显示逻辑核心数；内存将用量、应用 / 联动 / 压缩、压力、Swap 和历史曲线集中展示。
- GPU 仅在驱动返回有效读数时逐设备显示利用率，多个 GPU 的百分比不相加；部件汇总温度不归到某个具体设备。
- 存储新增启动卷已用 / 总量和普通可用空间，并与物理磁盘读写分开统计。APFS 共享容器空间不等同启动卷文件大小之和。
- 存在真实内置电池时，按可用数据展示电量、充电 / 供电状态、最大容量、循环次数及 macOS 时间估计；无内置电池的台式机隐藏该区，UPS 和外设电池不计入。
- 硬件区在固定页头和底部导航之间滚动，保留原有四类历史曲线、应用排行、菜单栏选项、用户设置及本地事件历史。

可选硬件的缺失或无效读数直接隐藏。GPU 和温度后台最快每 5 秒采样，卷容量和电池最快每 30 秒采样；较长的用户刷新间隔继续生效。无需管理员权限或特权辅助服务。

已在 Apple M4 iMac 检查真实 CPU / GPU / 存储读数及布局；本轮尚未在 Intel 或物理 MacBook 验证。可用性随 Mac 型号、驱动和 macOS 版本变化，详见[硬件模块及统计范围](../HARDWARE-MODULES.md)。

支持 macOS 13 及以上、Apple Silicon 和 Intel。沿用现有 ad-hoc 签名与 Sparkle 签名更新流程，尚未进行 Apple 公证。
