# PulseBar 1.13.0

- 总览改为紧凑单列，集中显示 CPU、内存、网络、存储及可用的 GPU / 电池数据。悬停硬件行打开独立详情浮窗，点击或固定后可保持打开；CPU 和内存详情包含应用排行。
- 总览、详情、设置和事件浮窗按内容调整高度，最高占当前屏幕可用高度的 80%。macOS 26 使用原生 Liquid Glass，较早系统使用原生弹出面板材质；控件遵循系统辅助功能设置。
- 菜单栏新增带清晰底轨的内存 / CPU 同心双环：外圈内存颜色对应系统内存压力，内圈 CPU 颜色对应占用率。悬停可查看圈层含义和实时读数。磁盘读写共用一个 MB/s，网络上下行共用另一个。
- 改善菜单栏反复展开和关闭时的交互，避免延迟点击事件误关新面板。详情窗在首次显示前应用实测高度，修复标题和顶部读数被裁切的问题；玻璃容器同步裁切外层圆角，并在尺寸变化时刷新窗口阴影。
- 改善应用排行中的辅助进程、WebKit / XPC 进程归属，在主应用资源计数无法读取时仍可识别所属应用；保留原有应用包和父进程查找作为回退。

支持 macOS 13 及以上版本、Apple Silicon 和 Intel。保留现有偏好和本地事件历史。继续使用临时签名和带签名验证的 Sparkle 更新流程，尚未经过 Apple 公证。
