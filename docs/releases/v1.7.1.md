# PulseBar 1.7.1

**[Download PulseBar.dmg](https://github.com/monaco-io/PulseBar/releases/download/v1.7.1/PulseBar.dmg)**

Open the DMG and drag PulseBar to Applications. Requires macOS 13 or later, on Apple Silicon or Intel.

## What's changed

- A single DMG download for installation and in-app updates.
- The signed update feed is hosted separately to keep the release downloads simple.
- All system monitoring, performance insights, settings, and local event history are preserved.

**Upgrading from 1.7.0 or earlier:** quit PulseBar and install this version manually once to migrate to the new update feed. Preferences and local event history are preserved. Future updates are available in **Settings → Software update**.

This app is ad-hoc signed and is not Apple notarized. If macOS blocks it, verify its source and choose **System Settings → Privacy & Security → Open Anyway** for PulseBar.
