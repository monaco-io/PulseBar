# PulseBar 1.7.1

[English](v1.7.1.md) | 简体中文

**[下载 PulseBar.dmg](https://github.com/monaco-io/PulseBar/releases/download/v1.7.1/PulseBar.dmg)**

打开 DMG，将 PulseBar 拖入 Applications。支持 macOS 13+、Apple Silicon 和 Intel。

- 发布附件只提供 DMG，安装说明和版本说明直接放在本页及 DMG 内。
- 应用内更新也下载同一个签名 DMG；更新清单迁移到独立地址。
- 保留全部系统监控、性能洞察、设置与本地事件功能。

**1.7.0 用户请手动安装本版一次。** 旧版更新地址依赖现已移走的附件，安装本版后恢复正常的应用内更新。

当前尚无 Apple Developer ID 公证；若 macOS 阻止打开，确认来源后在“系统设置 → 隐私与安全性”中选择“仍要打开”。
