# PulseBar 1.14.0

- 菜单栏改为细缝分层的三同心环：外圈为启动卷磁盘容量，中圈为内存，内圈为 CPU。三环均为 2.5 pt 粗细，间隔 0.6 pt 透明细缝，圆心保持空心。
- CPU 和磁盘使用相同分档：低于 60% 为绿，60–80% 为黄，超过 80% 使用危险色 `#FF8080`。内存仍依据 macOS 内存压力着色，压力紧张时也使用该危险色；深浅模式保持同一个危险色值。
- 悬停详情保持 CPU 在最上方，补充中圈、外圈对应关系、磁盘使用率及可用空间，辅助功能描述同步更新。磁盘显示开关同时控制容量环和读写速率。
- 保留固定宽度的上下读数：磁盘上读下写，网络上上传下下载，每组共用一个 MB/s 单位。

支持 macOS 13 及以上版本，兼容 Apple Silicon 和 Intel。保留原有偏好设置与本地事件历史，沿用现有临时签名与 Sparkle 签名更新流程；尚未经过 Apple 公证。
