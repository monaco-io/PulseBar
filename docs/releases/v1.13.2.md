# PulseBar 1.13.2

- Network readings now show upload (↑) above download (↓) in the menu bar. Hover details list live rates and session totals in the same order, and accessibility descriptions follow that order too.
- Keeps the fixed-width numeric columns and shared MB/s label, so changing rates do not shift neighboring menu bar items.

Requires macOS 13 or later, on Apple Silicon or Intel. Preferences and local event history are preserved. Releases retain the existing ad-hoc signing and signed Sparkle update flow; they are not Apple notarized.
