# v1.6 性能洞察设计

目标：保留 400 pt 的实时总览，通过右侧详情查看应用排行和事件。沿用现有设置侧栏，一次只打开一个侧栏；主面板保持固定四图，高度增至 640 pt 以容纳统计，底部操作固定，较长详情可滚动。

- 颜色沿用系统动态色：背景 #F5F5F7 / #242426，文字 #1D1D1F，下载蓝 #007AFF，CPU 橙 #FF9500，内存紫 #AF52DE，正常状态绿 #248A3D。压力同时用文字表达。
- 使用系统 SF 字体；实时数字 24–25 pt、标题 12–16 pt、详情 11 pt；数值等宽，应用名左对齐，数值右对齐。
- CPU / 内存标题和读数可展开排行，曲线保持独立悬停区域。共享时间游标固定查看时刻，显示实际样本；平均值按采样间隔加权，未采集区间不计入。
- 内存压力和 Swap 是总览中的紧凑状态行，趋势与详细说明放进内存侧栏。事件有单独的底部入口；详情显示触发规则和当时的 CPU / 内存前五名。
- 事件只记录持续状态，默认 CPU ≥ 85% 持续 30 秒、内存压力偏高或紧张持续 10 秒；同一状态一段持续过程只记录一次，恢复后可重新触发。通知默认关闭，冷却时间独立于事件记录。
- 事件保留最近 7 天、最多 200 条，仅在本机保存；曲线继续遵守本次运行的 24 小时上限。读取失败或休眠中断会重置检测时长，不能据此声称持续异常。

布局：

```
脉动                           每 2 秒更新 | CPU 占用排行       ×
CPU >                  内存 >             | 应用          CPU / 内存
读数 + 曲线 + 平均 / 峰值                 | 前五项
内存压力        Swap 用量 / 变化          | 打开活动监视器
磁盘读写 + 曲线 + 平均 / 峰值             |
网络收发 + 曲线 + 平均 / 峰值             |
设置            事件 (n)     重置   退出 |
```

评审：原生监控场景继续使用系统字体和语义颜色。新增信息沿实时总览 → 应用详情 → 历史事件展开，避免把所有排行和事件直接塞入主面板。
