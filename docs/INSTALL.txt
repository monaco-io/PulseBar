PulseBar — Installation and updates

Requires macOS 13 or later; supports Apple Silicon and Intel.

1. Install and update the main PulseBar app through the Mac App Store.
   New main-app versions are no longer published on GitHub.
2. For optional app rankings and hardware temperatures, open PulseBar Settings
   and choose Download Helper Installer. The link downloads the PKG directly.
3. Open PulseBar-Helper.pkg and follow macOS Installer. It places the helper
   in ~/Applications, without dragging files or administrator access.
4. Return to PulseBar Settings, choose Open Helper, then Enable Helper.
   Approve the background item in System Settings if macOS requests it.
5. To remove the helper, disable it first, then move its app to Trash.

Basic monitoring works without the helper. Historical GitHub main-app files
and their update feed remain available, but receive no new app versions.
