PulseBar — Installation and updates

Requires macOS 13 or later. One universal app supports Apple Silicon and Intel.

1. Open PulseBar.dmg and drag PulseBar to Applications.
   You can use ~/Applications if you do not have administrator access.
2. Launch PulseBar from Applications. Readings appear in the menu bar;
   the app does not show a Dock icon.
3. This release is ad-hoc signed and is not Apple notarized. If macOS blocks it,
   verify that it came from the monaco-io/PulseBar GitHub Release, then use
   System Settings > Privacy & Security > Open Anyway for PulseBar.
   Do not disable Gatekeeper or change global security settings.
4. Click the menu bar readings > Settings > Software update to check for updates.
   Automatic checks run daily; you choose when to download and install.
   Both the DMG and the update feed are cryptographically signed.
5. Versions 1.7.0 and earlier need one manual installation of 1.7.1 or later
   to migrate to the current update feed. Quit the old version before replacing it.
   Preferences and local event history are preserved.
