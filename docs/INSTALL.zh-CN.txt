PulseBar — 安装与更新

支持 macOS 13 或更新版本、Apple Silicon 和 Intel。

1. 主程序只通过 Mac App Store 安装和更新，GitHub 后续只发布助手插件。
2. 需要应用排行和硬件温度时，打开 PulseBar 设置，点击“下载安装助手”。
   链接会直接下载 PKG，不经过 GitHub 发布页。
3. 打开 PulseBar-Helper.pkg，按 macOS 安装器提示完成安装。
   助手会放入个人 ~/Applications，无需拖拽文件或管理员权限。
4. 回到 PulseBar 设置，点击“打开助手”，再选择“启用助手”。
   如系统要求允许后台项目，按提示到系统设置中确认。
5. 卸载前先停用助手，再将助手移入废纸篓。

基础监控不依赖助手。历史 GitHub 主程序安装包和更新清单保留兼容，
但后续不再发布主程序新版。

助手说明：https://github.com/monaco-io/PulseBar/blob/main/docs/HELPER.md
